Cartório · Automação de Escrituras

Manual de instalação da app

Passo a passo para instalar no computador de cada funcionária, sem erros. Copia os comandos com o botão Copiar e clica os links para descarregar.

Antes de começar: tem à mão a chave da API do Claude (começa por sk-ant-…). É a mesma para todos os PCs; o instalador vai pedi-la.
1

Instalar o Python

Descarrega e instala o Python. Marca a caixa “Add Python to PATH” no início do instalador (é o passo mais importante).

python.org/downloads
2

Instalar o LibreOffice

Serve para ler as escrituras .doc antigas. Instala com as opções por defeito.

libreoffice.org/descarregar
3

Pôr o código em C:\cartorio-automacao

Opção A — recomendada (com Git, permite atualizar depois)

Instala o Git e depois corre o comando no PowerShell:

git-scm.com/download/win
PowerShell
git clone https://github.com/RuiSousaFerreiraIMS/cartorio-automacao.git C:\cartorio-automacao
Opção B — sem Git

Copia a pasta do projeto (por pen ou rede) para C:\cartorio-automacao.

4

Correr o instalador

Abre o PowerShell (menu Iniciar → escreve “PowerShell” → Enter) e cola este comando:

PowerShell
powershell -ExecutionPolicy Bypass -File C:\cartorio-automacao\instalar.ps1

Instala tudo sozinho (uns minutos de download). A meio pede a chave da API — cola a sk-ant-… e Enter.

5

Confirmar que ficou bem

No fim, os testes automáticos correm. Só está pronto quando aparecer:

RESULTADO: TUDO OK.

Se aparecer algum [FALHA], o resumo diz o que falta. Corrige e corre o instalar.ps1 outra vez. (Ver a tabela em baixo.)

6

Testar a app

Duplo-clique no atalho “Cartorio Escrituras” no ambiente de trabalho. Abre o browser na app. Carrega uma escritura de exemplo e vê se extrai os campos.

Reconfirmar depois (sem reinstalar)

A qualquer momento, para correr só os testes:

PowerShell
C:\cartorio-automacao\.venv\Scripts\python.exe C:\cartorio-automacao\verificar_instalacao.py

Atualizar quando o código mudar

Só na Opção A (com Git). Corre linha a linha:

PowerShell
cd C:\cartorio-automacao
git pull
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe verificar_instalacao.py

Se algum teste falhar

O que fazer para cada [FALHA] mais comum:

Versão do Python
Reinstalar o Python marcando “Add Python to PATH”.
Pacote pyautogui / opencv…
O pip falhou (internet?). Correr o instalar.ps1 outra vez.
Leitor de .doc antigo
Instalar o LibreOffice (passo 2) e recorrer o verificador.
Chave da API
Correr o instalar.ps1 outra vez e colar a chave sk-ant-….
Teste à API (internet)
Chave errada ou sem ligação. Confirmar a chave e a internet.
Se um PC der uma falha que não percebes, envia o ficheiro de log em C:\cartorio-automacao\logs\ ao Rui.
